# Design history

`specs/` and `plans/` are the design documents and implementation plans
behind each feature, dated by the day the work was planned. They are kept as
history: they record why a decision was made and which alternatives were
rejected, and several code comments cite them by path.

They are **not** status documents. Every feature described here has shipped
(see `CHANGELOG.md` for the release that carried it); the unchecked task
boxes and "proposed" headers inside the plans reflect the moment they were
written, not the current state of the code. For what a contributor needs day
to day, read the code, `THREAT_MODEL.md`, `docs/ROADMAP.md`, and
`CONTRIBUTING.md`.
